# Architecture Decision Records

This directory records architecture decisions for Neighborhood Guru.

Each ADR is a markdown file named `NNNN-short-title.md`, numbered in the order the decision was proposed. Status values are **Proposed**, **Accepted**, **Superseded**, or **Rejected**.

| ADR | Title | Status |
| --- | --- | --- |
| [0001](./0001-opt-in-neighborhood-sync.md) | Opt-in neighborhood-data sync with a pluggable store | Proposed |

New architecture tracks (sync, storage backends, auth/data-plane coupling, and similar) should start with an ADR before implementation PRs. See [CONTRIBUTING.md](../../CONTRIBUTING.md).
